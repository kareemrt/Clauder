## Overview

Fractal Studio is a command-line fractal art generator written in **100% pure Python**
using only the standard library (`math`, `struct`, `zlib`, `base64`).
It renders six mathematically distinct fractals with smooth continuous-iteration
coloring, writes pixel-perfect PNG files without PIL or numpy, and packages
everything into a self-contained HTML gallery you can open in any browser.

## Features

- **Six fractal types** — Mandelbrot set (classic + deep-zoom variants), Julia set,
  Burning Ship, and Newton cubic (z³ = 1)
- **Smooth coloring** — continuous iteration count algorithm eliminates harsh banding
- **Six color palettes** — Inferno, Plasma, Viridis, Electric, Fire, Psychedelic
- **Pure-Python PNG writer** — encodes 24-bit RGB PNGs using only `struct` + `zlib`
- **Self-contained HTML gallery** — all images embedded as base64 data URIs
- **Colorized ASCII preview** — 24-bit ANSI color rendering directly in the terminal
- **Configurable CLI** — resolution, preset selection, palette override, output path
- **No external dependencies** — runs on any Python 3.8+ installation

## Quick Start

```bash
# Clone the repo
git clone https://github.com/kareemrt/clauder.git
cd clauder

# No installation needed — run directly
python -m fractal_studio

# Open the gallery
open fractal_output/gallery.html       # macOS
xdg-open fractal_output/gallery.html  # Linux
start fractal_output/gallery.html     # Windows
```

The default run produces six PNG files and a `gallery.html` at 320 × 240 px.
For higher-quality output, increase the resolution:

```bash
python -m fractal_studio -W 1024 -H 768
```

### Examples

```bash
# List all preset names
```

## The Six Fractals

### 1. Mandelbrot Set — Classic View

The canonical view: iterates **z → z² + c** from z = 0 for each complex c.
The interior (bounded orbit) is rendered black; the exterior is colored by
how quickly the orbit escapes to infinity.

```
Viewport  : Re in [-2.75, 1.25],  Im in [-1.50, 1.50]
Iterations: 256
Palette   : Inferno
```

### 2. Mandelbrot — Seahorse Valley

A deep zoom at **c ≈ −0.7436 + 0.1314i**, revealing the infinite
self-similar spirals at the boundary between order and chaos.

```
Viewport  : 0.0034 complex units wide   (~850x zoom)
Iterations: 512
Palette   : Plasma
```

### 3. Mandelbrot — Elephant Valley

Near **c ≈ 0.2812 + 0.0097i**, repeated elephant-tusk mini-brot structures
appear at ever-finer magnifications — a classic demonstration of self-similarity.

```
Viewport  : 0.008 complex units wide    (~375x zoom)
Iterations: 512
Palette   : Viridis
```

### 4. Julia Set — Douady's Rabbit

The Julia set for **c = −0.123 + 0.745i** exhibits threefold "Douady rabbit"
symmetry, discovered by Adrien Douady in the 1980s.

```
Parameter : c = -0.123 + 0.745i
Viewport  : 3.2 x 2.4 complex units
Iterations: 256
Palette   : Electric
```

### 5. Burning Ship

A dramatic variation: replace the squaring step with
**z → (|Re(z)| + i|Im(z)|)² + c**.
The result looks strikingly like a ship engulfed in flames.

```
Viewport  : Re in [-2.10, 1.10],  Im in [-1.80, 0.80]
Iterations: 256
Palette   : Fire
```

### 6. Newton Fractal — z³ = 1

Newton's method applied to **f(z) = z³ − 1**.
The three roots of unity (colored red, blue, green) form fractal boundaries
between basins of attraction, with brightness proportional to convergence speed.

```
Roots     : 1,  exp(2πi/3),  exp(4πi/3)
Viewport  : 3.0 x 2.25 complex units
Iterations: 64
Coloring  : root-based RGB + convergence brightness
```

## Color Palettes

| Name          | Description                               | Used by              |
|---------------|-------------------------------------------|----------------------|
| `inferno`     | Black → purple → orange → pale yellow     | Mandelbrot Classic   |
| `plasma`      | Deep blue → purple → pink → yellow        | Seahorse Valley      |
| `viridis`     | Dark violet → teal → yellow-green         | Elephant Valley      |
| `electric`    | Black → deep blue → cyan → white          | Julia Rabbit         |
| `fire`        | Black → dark red → orange → white         | Burning Ship         |
| `psychedelic` | Cycling hues: violet → blue → green → red | (override anytime)   |

All palettes use **linear interpolation** between control-point colors.
The cyclic coloring formula `t = (smooth_iter % cycle) / cycle` maps the
continuous escape count to `t ∈ [0, 1]` for palette lookup.

## Algorithms

### Smooth Coloring (Continuous Iteration Count)

Naive escape-time coloring produces harsh "staircase" banding. Fractal Studio
uses the **normalized iteration count** formula:

```
smooth(n, z) = n + 1 - log2( log2(|z|) )
```

where `n` is the integer iteration count at escape and `|z|` is the magnitude
of the final orbit value. Because `|z|` varies continuously, consecutive
escape-time contours blend seamlessly.

### Pure-Python PNG Encoder

```
PNG file layout:
  [8-byte signature]
  IHDR chunk  →  width · height · bit_depth=8 · color_type=2 (RGB)
  IDAT chunk  →  zlib-compressed scanlines, each prefixed with filter byte 0
  IEND chunk
```

Each chunk is framed as `[length][tag + data][CRC-32]`.
The compressor uses `zlib.compress(..., level=6)` from the standard library.

### Newton's Method on the Complex Plane

For f(z) = z³ − 1, the complex Newton iteration is:

```
z_{n+1} = z - f(z) / f'(z) = z - (z³ - 1) / (3z²)
```

Complex division `a / b` is computed as `(a * conj(b)) / |b|²` to avoid
any imaginary-unit arithmetic. Convergence is detected when `|z - root|² < ε²`.

## Performance

All computation is pure Python — no Cython, no C extensions, no numpy.

| Resolution  | All 6 presets | Single preset |
|-------------|---------------|---------------|
| 320 × 240   | ~4 s          | ~0.5 s        |
| 480 × 320   | ~8 s          | ~1.2 s        |
| 800 × 600   | ~25 s         | ~4 s          |
| 1024 × 768  | ~45 s         | ~7 s          |

Deep-zoom presets (Seahorse, Elephant) are ~2× slower due to higher
`max_iter` limits. Python 3.11+ is recommended for its optimised
interpreter loop.
