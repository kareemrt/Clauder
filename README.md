## Projects

### [CodeHaiku](./codehaiku/) 🌸

> *Poetry distilled from source code*

Transform any source code file into authentic haiku poetry. CodeHaiku mines identifiers,
comments, and string literals from your code — then algorithmically composes them into
valid 5-7-5 syllable verse using a custom syllable-counting engine.

```bash
cat main.py | codehaiku pipe
```

```
Shadow fading dreams
Append transform wandering
Fragment ancient watch
```

**Supports:** Python, JavaScript, TypeScript, Rust, Go, Java, C/C++, Ruby, and more.
