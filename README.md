# ⚡ Clauder — Git Time Machine

> **Archaeologist for your codebase.** A Python CLI that turns any git repository's history into a beautiful terminal dashboard and interactive HTML report.

```
  ══════════════════════════════════════════════════════════════════
  ⚡  CLAUDER — Git Time Machine
  ══════════════════════════════════════════════════════════════════
  Repository    my-project
  Branch        main
  Commits       1,847
  Authors       12
  Active days   623
  Lines +       +198,341
  Lines −       −87,210
  Earliest      2022-03-01
  Latest        2024-11-15
  ══════════════════════════════════════════════════════════════════
```

---

## What it does

Clauder reads your git history and renders:

| Feature | Terminal | HTML |
|---|---|---|
| Contribution heatmap (GitHub-style) | ✅ ANSI color blocks | ✅ Interactive, hover tooltips |
| Weekly velocity sparkline | ✅ ASCII bar chart | — |
| Contributor bar chart | ✅ Colored bars | ✅ Per-author breakdown |
| File hotspots | ✅ Most-changed files | ✅ With commit counts |
| Hourly activity chart | ✅ 24-hour histogram | ✅ |
| Commit timeline | ✅ Color-coded by author | ✅ +/− line counts |

## Installation

```bash
git clone https://github.com/kareemrt/clauder.git
cd clauder
pip install -r requirements.txt
```

**Requirements:** Python 3.9+, `colorama`, and `git` in your PATH.

## Usage

### Terminal dashboard

```bash
# Analyze the current directory
python main.py

# Analyze any repo
python main.py /path/to/your/repo

# Show the last 26 weeks instead of 52
python main.py /path/to/repo --weeks 26

# Skip the timeline (faster for large repos)
python main.py /path/to/repo --no-timeline
```

### HTML report

```bash
# Export to clauder-report.html (default name)
python main.py /path/to/repo --html

# Export to a specific file
python main.py /path/to/repo --html my-report.html
```

Open the `.html` file in any browser — it's fully self-contained (no CDN, no network).

## How it works

```
         git log / numstat
              │
              ▼
     ┌─────────────────┐
     │  analyzer.py    │  ← parse commits, authors, stats, hotspots
     └────────┬────────┘
              │  Commit[], author_stats, date_map, hotspots, hour_map
              ▼
     ┌─────────────────┐        ┌─────────────────┐
     │  visualizer.py  │        │  reporter.py    │
     │  (terminal)     │        │  (HTML export)  │
     └────────┬────────┘        └────────┬────────┘
              │                          │
              ▼                          ▼
       ANSI dashboard            self-contained .html
       in your terminal          open in any browser
```

### Data pipeline

1. **`analyzer.py`** — calls `git log --numstat` in a single pass to collect every commit's metadata and line-change stats without spawning a subprocess per commit (handles repos with 10k+ commits efficiently).
2. **`visualizer.py`** — renders 7 visualization types using ANSI 256-color escape codes via `colorama`. No curses, no dependencies beyond the stdlib.
3. **`reporter.py`** — generates a zero-dependency HTML file with all data embedded as a JSON blob; JavaScript renders the heatmap, bar charts, and timeline directly in the browser.

## CLI Reference

```
usage: main.py [-h] [--html [FILE]] [--weeks N] [--no-timeline] [--no-hours] [repo]

positional arguments:
  repo           Path to git repository (default: .)

options:
  -h, --help     show this help message and exit
  --html [FILE]  Export HTML report (default: clauder-report.html)
  --weeks N      Weeks of heatmap to display (default: 52)
  --no-timeline  Skip the commit timeline
  --no-hours     Skip the hourly activity chart
```

---

## Design decisions

- **Single-pass `numstat`** — instead of running `git show --stat` per commit (O(n) subprocess spawns), one `git log --numstat` call gives all line stats in O(1) subprocesses.
- **No heavy dependencies** — only `colorama` (cross-platform ANSI); the HTML report uses zero external libraries.
- **Self-contained HTML** — the entire report, including all JavaScript and CSS, fits in one file you can email or archive.
- **Works on any repo** — point it at any directory with a `.git` folder.
