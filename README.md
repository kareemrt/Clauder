## What Is GitNarrator?

Every codebase has a hidden story — late-night sprints, pivotal refactors, months of silence before a breakthrough. **GitNarrator** reads your git history and, powered by Claude AI, writes that story for you.

It produces:
- A **streaming AI narrative** told like a documentary
- A **beautiful Rich terminal dashboard** with ASCII heatmaps, contributor charts, and chapter cards
- A **self-contained HTML report** you can share with your team

---

## Features

| Feature | Description |
|---|---|
| **AI Narrative** | Claude generates a chapter-by-chapter story of your project's evolution |
| **Commit Timeline** | ASCII heatmap visualizing weekly commit activity |
| **Chapter Detection** | Automatically identifies "eras" in your project by time gaps and activity bursts |
| **Contributor Charts** | Color-coded bar chart of every developer's impact |
| **Language Breakdown** | File extension analysis showing your tech stack over time |
| **Hottest Files** | Discovers the most frequently changed files (your "scar tissue") |
| **HTML Export** | Dark-themed, shareable HTML report with all charts and the full narrative |
| **Streaming Output** | Claude's story streams live to your terminal as it's generated |

## Installation

```bash
# Clone the repo
git clone https://github.com/kareemrt/clauder.git
cd clauder

# Install dependencies
pip install -r requirements.txt

# Set your Anthropic API key
export ANTHROPIC_API_KEY="your-key-here"
```

## Usage

### Full Analysis (recommended)

```bash
python main.py analyze /path/to/your/repo
```

Produces: terminal dashboard + streaming AI narrative.

### With HTML Export

```bash
python main.py analyze /path/to/your/repo --html report.html
```

### Stats Only (no AI, no API key needed)

```bash
python main.py stats /path/to/your/repo
```

### AI Narrative Only

```bash
python main.py story /path/to/your/repo
```

### Options

```
Usage: main.py analyze [OPTIONS] [REPO_PATH]

  Analyze a git repository and tell its story.

Options:
  -n, --max-commits INTEGER  Max commits to analyze (default: 500)
  --html TEXT                Export HTML report to this path
  --no-story                 Skip AI narrative generation
  --help                     Show this message and exit.
```

## How Chapter Detection Works

GitNarrator automatically segments your commit history into meaningful "chapters" by detecting:

1. **Time gaps** — A gap of more than 14 days between commits signals a new phase (vacation, planning, pivot)
2. **Activity bursts** — Groups of ≥30 commits are capped into a chapter to keep narratives focused

Each chapter is then enriched with:
- Dominant contributors during that period
- Most-changed files (the "scar tissue" of that era)
- Net lines added/deleted
- Sample commit messages fed to Claude for context

| Task | Model | Why |
